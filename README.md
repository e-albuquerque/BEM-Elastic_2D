# BEM-Elastic_2D: A boundary element code to solve 2d elastic problems
---
The goal of the BEM-Elastic_2D project is to provide a platform that can be used with Gmsh to quickly solve bidimensional boundary element elastic problems.


## Installation
---
git clone https://github.com/e-albuquerque/BEM-Elastic_2D.git

cd BEM-Elastic_2D

pip install -q build

python -m build

pip install dist/Bem2d_e-0.0.1-py3-none-any.whl
